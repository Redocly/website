# Get started with Realm

{% configOptionRequirements products=$frontmatter.products plans=$frontmatter.plans /%}

Redocly projects are managed and deployed on Reunite, the Redocly cloud platform.
For development, you can use the built-in Reunite editor, or work locally using your favorite editor.

Start your first project in your browser with Reunite, with your local development tools, or by generating it with AI:

- [Get started with the Reunite editor](start-reunite-editor.md): Use the built-in editor in Reunite.
- [Get started locally](start-local-dev.md): Use a code editor on your local device.
- [Create a project with AI](../reunite/project/create-project/with-ai.md): Describe your documentation and let Reunite generate the project.

Realm and other Redocly products receive regular updates.
If you're working locally, or have defined a version of Redocly products in your project, consider [updating to the latest version](./upgrade-realm-version.md).
